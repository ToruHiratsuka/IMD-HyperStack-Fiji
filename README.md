# IMD HyperStack for Fiji
Generate intensity-modulated ratio images from HyperStacks.

## Features
- HyperStack compatible
- Intensity weighted pseudocolor display
- Multiple LUTs
  - 8colours
  - jet
  - White-Red
  - Red

## Installation
1. Download Fiji
2. Open Script Editor
3. Load IMD_HyperStack_1.0.0.py
4. Run

## Usage
0. Download the lut files (8colours.lut; Whire-Red.lut; jet-lut) and move to the Fiji>luts
1. Open numerator and denominator images
2. Run the script
